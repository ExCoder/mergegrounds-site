# Security policy

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/ExCoder/mergegrounds-site/security/advisories/new).
Do not publish an unpatched vulnerability, bypass, exposed credential, or
exploit detail in an issue or discussion.

The newest release and the default branch receive security fixes. This site
does not process repository source, credentials, or uploaded content. A
vulnerability in the MergeGrounds admission control belongs in the
[core repository](https://github.com/ExCoder/mergegrounds/security/advisories/new).
